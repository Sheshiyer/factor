# Departments

Add a folder when the company has that function. Suggested contents:

```text
departments/<function>/
  playbook.md
  checks.md
  tools.md
  examples/
```

`playbook.md` is how the work is done. `checks.md` is what must be true before it comes back. `examples/` holds an accepted piece and a rejected piece, with the reason. `tools.md` names accounts this desk may use. It does not hold secrets.

Do not add a department in advance of the work.
