# __COMPANY__

This repo is the company. Hermes reads it. The profile that operates it is `factor` (Claude). Code cards go to the Codex profile.

## Read

Read `SOUL.md`, then `wiki/index.md`. Open a linked page only when its line matches the work. Standing facts also live in `context/`. A line that still says `FILL:` is unknown. Stop and name the file. `raw/` is the archive and is not edited after it lands.

A card may name extra files. Do not load the rest of the repo "for context."

## Write

Drafts go in the desk folder or the project folder named on the card. A correction updates the context file, the example, or the skill that was wrong. This file stays the rules of the road. It does not collect one-off patches.

## Sign-off

Money, people, legal, public messages, and paid tool calls wait for an approval comment on the card.

## Connectors

`connectors/enabled.yaml` is the list. An id that is absent is off. Credentials live in the Hermes profile `.env`, never in this repo.

## Desks

Add a department when a real function exists. Copy nothing from another company. One folder, one playbook, one checks file, and examples of work that was accepted and work that was rejected.
