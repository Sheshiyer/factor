# Projects

One folder per effort:

```text
projects/<name>/
  brief.md
  decisions.md
  production/
  results.md
```

`brief.md` holds the goal, the audience, the offer, and the constraints. The founder approves the brief before a connector runs against it. `decisions.md` records what was agreed and why. `results.md` records what happened, with the period and the metric definitions.
