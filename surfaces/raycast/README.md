# Raycast

Add this folder in Raycast under Settings, Extensions, Script Commands. The command is Factor. Type the job, pick a room, and it writes the same intent as the menu bar.

The company folder is `~/Library/Application Support/Factor/company.path`. Choose it once in the menu. This folder holds no keys.

## Language and learning

English is the default. `Factor — Français` provides French argument labels with the same canonical room values and intent format. Its label alone does not change the company's saved language.

Use `Factor — Language / Langue` to save `en` or `fr` in the selected company's `preferences.json`. This is the same choice used by the Mac menu, onboarding CLI and Factor's Hermes instructions. `Factor — Learn / Découvrir` opens a selected local guide or media asset; it uses the saved language for bilingual guides and labels the French-only media. No resource opens before a deliberate selection.
