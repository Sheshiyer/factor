# Factor v0.6.0 — Knowledge curation and bilingual onboarding

Factor now carries research into reviewed company knowledge and makes onboarding available in English and French. The learning library travels with the repository: no access to the private NotebookLM notebook is required.

## What changed

- **Knowledge curation:** source revisions, attributed claims, conflict/gap tracking, reviewed corrections and reproducible local content packets.
- **Approval boundary:** sending, spending and publishing require explicit approval of the exact action and content. Confidence cannot substitute for permission. Local approval records validate the request; they do not authenticate a person or execute external actions.
- **Bookmark intake:** repeatable intake from an FT cache, retaining provenance and unavailable article bodies as explicit gaps. A source-grounded Hermes learning protocol defines review and fresh-session evaluation.
- **English and French:** English remains the default. Save French per company or choose a temporary CLI language. Mac, Raycast and Factor's Hermes instructions expose the same preference while retaining canonical data keys and existing company documents.
- **Learning library:** reviewed EN/FR framework guides and operator playbooks; two French slide decks in PDF/PPTX, one video and two infographics. Seven media exports ship in the repository and as release downloads.
- **Installation:** a copyable [install/upgrade prompt](https://github.com/Sheshiyer/factor/blob/v0.6.0/prompt-install.md) covers company backups, distribution-source checks, Hermes doctor, the messaging gateway and the Mac runner.

## Upgrade or install

Use a clean checkout of v0.6.0 and paste `prompt-install.md` into your coding session. The prompt distinguishes fresh installs from upgrades, checks the installed profile's recorded source and preserves company data and configuration. Updating the repository alone does not update an installed Hermes profile.

From the repository root:

```sh
python3 scripts/onboard.py --resources
python3 scripts/onboard.py --language fr --steps
python3 scripts/onboard.py --company /absolute/path/to/company --set-language fr
```

Use `--set-language en` to return to English. Existing companies without a language preference continue in English. Visual media remain French in either interface language.

## Verification and current limits

- 300 Python tests pass; 9 tests against the production Swift target pass; the Mac package builds.
- All seven bundled media files match the recorded sizes and SHA-256 hashes in `docs/assets/manifest.json`.
- Mac menu visual acceptance (UI-01), Raycast GUI registration and live Hermes language behavior remain unverified. The Mac app is unsigned and local; this release supplies source, not a signed installer.
- The real company/profile Hermes learning pilot remains pending. The framework does not claim autonomous model improvement or scheduled learning acceptance.
- FT sync authentication and two linked article-body gaps remain documented. Intake is based on the observed user-refreshed cache, not a claim of complete current X coverage.
- Video frames and decoding were checked; narration has not been fully listened to or transcribed. The learning infographic must be read with: **“Protocole proposé ; pilote Hermes à valider.”**

Details: [learning library](https://github.com/Sheshiyer/factor/blob/v0.6.0/docs/learning.md), [onboarding verification](https://github.com/Sheshiyer/factor/blob/v0.6.0/docs/onboarding-verification.md), [native learning protocol](https://github.com/Sheshiyer/factor/blob/v0.6.0/docs/hermes-learning-loop.md).

## Français

Factor v0.6.0 relie les sources à une connaissance d’entreprise relue, avec une traçabilité des révisions, des affirmations, des corrections et des lacunes. L’envoi, la dépense et la publication exigent une approbation explicite portant sur l’action et le contenu exacts ; un score de confiance ne suffit pas.

L’accueil est disponible en anglais et en français. L’anglais reste la langue par défaut ; le choix français peut être enregistré pour chaque entreprise. Les documents existants et les identifiants techniques restent inchangés. Les guides sont bilingues ; les deux présentations, la vidéo et les deux infographies sont en français et sont inclus dans le dépôt et les fichiers de cette version.

Pour installer ou mettre à jour, ouvrez `prompt-install.md` dans une session de votre assistant de code. Il prévoit les sauvegardes, le contrôle de la source du profil, Hermes doctor, la passerelle de messagerie et le lanceur Mac. La mise à jour du dépôt ne met pas automatiquement à jour le profil Hermes installé.

Les 300 tests Python et les 9 tests Swift passent, et la compilation Mac réussit. La validation visuelle du menu Mac, l’enregistrement dans Raycast et le comportement linguistique réel d’Hermes restent à vérifier. **Le pilote d’apprentissage sur une entreprise et un profil réels reste à valider.** L’application Mac est locale et non signée. La narration vidéo n’a pas fait l’objet d’une écoute intégrale ; les limites des sources et des médias sont conservées dans la [bibliothèque de ressources](https://github.com/Sheshiyer/factor/blob/v0.6.0/docs/learning.fr.md).
