# Factor roadmap

Three releases. One employee. The founder keeps the decisions.

Discovery, locked from the work already in the repo:

- Depth is standard. Eighty tasks, not a deeper split.
- Delivery is phased. Release 1 makes the handoff trustworthy. Release 2 adds the doors. Release 3 runs the first rooms.
- The team is one founder.
- CI is a single test workflow, due in Release 1.
- Claude and Codex write. Jev only picks, scores, and says yes or no. Options come from files.
- Hermes session memory is a scratch pad. Instinct is one screen. Company memory stays on disk.

## Releases as shipped

Inception, memory, Jev, evals, and rollback shipped as v0.2.0. The menu-bar tray is the last release. Open it with `apps/mac/run.sh`. It is unsigned and local.

R2 is Raycast and Hermes on the same intent. R3 is the rooms. `tasks/todo.md` is the earlier ledger, not the queue.

## Phase 1 waves

Release 1 is three waves. Each wave has two swarms that can proceed once the wave's contract is written.

**Wave 1, Contract.** Product swarm writes the budgets and the handoff in language a founder can read. Data swarm makes those budgets fail a check when they are exceeded.

**Wave 2, Jev.** Backend swarm defines the questions Jev is allowed to answer. QA swarm proves a draft that invents a price fails, and a missing TypeSafe install stops the card.

**Wave 3, Proof.** CI swarm runs the tests on every push. Product swarm checks the README still tells the story in the same order as the files.

## Phase 2 waves

**Wave 1, Raycast.** A command that writes the same intent the Mac app already writes.

**Wave 2, Hermes.** The employee reads instinct, then one page, and opens a card. A healthy room sends nothing.

## Phase 3 waves

**Wave 1, Content.** A weekday list. The founder keeps, drops, or develops. Nothing publishes.

**Wave 2, Numbers.** Figures plus the page they came from. Silence when no line was crossed.

**Wave 3, Approval.** Send, spend, and publish need 0.85 or a yes. Partners and money draft only.

The next release is specified in `specs/` and tracked as R1 issues. `tasks/todo.md` is the earlier ledger.

## Verification

A wave is done when its tasks have the proof named on each one: a test, a file check, or a sample intent. A release is done when its row in the table above is true on `main`.

## Risks

Jev is not installed yet. Release 1 must stop cleanly when the TypeSafe skill is absent, and must not pretend Claude is Jev.

The Mac applet and Raycast command are doors. They write a file. They do not become a second agent.

Compaction must drop or keep original lines. A summary would erase a path or a refusal.
